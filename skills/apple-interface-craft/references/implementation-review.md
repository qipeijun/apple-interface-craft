# 界面实施与验收

Apple 式体验最终必须由真实状态、响应、语义、适配和性能支撑。视觉像 Apple 但交互迟钝、状态错误或不能访问，不符合 Craft。

## 实施前状态表

只列当前任务实际涉及的状态，并确认每一项的业务来源：

| 维度 | 需要确认 |
| --- | --- |
| 内容 | 默认、空、长文本、图片缺失、内容更新 |
| 请求 | 未请求、加载、成功、业务失败、网络失败、取消 |
| 控件 | 可用、按下、选中、聚焦、悬停、禁用、处理中 |
| 权限 | 可查看、可操作、无权查看、无权操作 |
| 流程 | 返回、取消、撤销、重试、恢复、离开后返回 |
| 布局 | 旋转、分屏、窗口缩放、不同安全区域、目标平台文字缩放 |
| 输入 | 触摸、指针、键盘、语音、辅助技术 |
| 动效 | 正向、反向、中断、Reduce Motion |

业务状态与权限状态分别建模。不能用视觉禁用代替权限判断，也不能用动画中的临时 class 代表持久业务状态。

## 组件与语义

- 复用项目现有组件、设计令牌、图标和路由模式。
- Apple 原生平台优先使用系统组件与 API，以获得平台行为、适配和无障碍能力。
- Web 中优先语义 HTML 和现有框架能力；自定义控件必须补齐键盘、焦点、名称、状态和触摸行为。
- 小程序和混合 App 先确认渲染层、宿主组件与原生桥职责；共享框架不意味着平台行为相同。
- 控件的视觉状态绑定真实可操作性和业务状态，不用局部样式制造假反馈。
- 共享组件改动需要检查所有调用方、权限组合和属性透传，避免只修当前页面。

## 异步与反馈

- 点击后立即显示控件已收到操作，再展示真实请求中的状态。
- 防止重复提交必须与请求生命周期一致，不用固定延时解锁。
- 进度来源于真实任务数据；无法估计时诚实使用不确定状态。
- 错误信息使用后端已确认的契约，不猜字段、不吞错、不统一伪装为网络错误。
- 重试、取消和恢复只在后端和业务真实支持时提供。
- 成功后更新当前对象、列表、导航和辅助技术可感知状态，避免只弹 Toast。

## 动效实施

- 先建立状态与状态关系，再写动画。
- 优先使用项目已有成熟动画能力、系统导航转场或 Apple 平台 API。
- 手势动画连续读取当前位移和速度；中断时从当前视觉状态继续。
- Web 优先动画合成友好的属性，限制大面积滤镜、模糊和阴影的持续开销。
- 动画结束事件不能是唯一状态收口路径；取消、跳过或 Reduce Motion 时仍正确。
- 清理监听器、手势订阅、计时器和临时性能提示，避免重复注册与内存泄漏。

## 响应与稳定性

Apple 的即时反馈和跟手感要求主线程及时响应输入。检查：

- 点击、拖动、滚动和键盘输入是否立即产生下一帧反馈；
- 大列表、图片、模糊、阴影和布局计算是否造成卡顿；
- 动态内容是否预留空间，避免界面跳动和错误点击；
- 图片、字体和异步组件是否按任务优先级加载；
- 低性能设备、后台恢复和网络变慢时状态是否仍可信。

不要仅凭动画参数推断“丝滑”，必须在运行态观察输入响应、帧率、滚动和中断行为。

## 分层验证

根据改动风险选择验证并诚实命名：

1. **静态检查**：类型、lint、组件编译、语义结构和 diff 检查，只证明代码层面成立。
2. **自动化测试**：验证状态、事件、焦点、Reduce Motion 和关键回归。
3. **构建**：仅在影响构建产物、依赖、类型声明、发布流程或用户明确要求时执行。
4. **运行态验证**：在已授权的开发服务或浏览器 / 模拟器中检查实际渲染结构、布局、交互、日志和性能；只有 Web 渲染层才检查 DOM，涉及原生桥时另查宿主。
5. **设备与辅助技术验证**：按任务在目标设备及其文字缩放、辅助技术、键盘和系统设置中验证。
6. **人工体验验收**：判断层级、跟手、空间连续性、材质和情绪是否符合目标；不能由构建成功替代。

若项目规则要求先征得浏览器、模拟器或设备调试许可，先说明运行态验证能补足什么证据并等待授权。

## 审查输出

审查结论按影响排序，每个问题包含：严重程度、准确位置、可复核证据、用户或业务影响、最小修复方向和所需验证。代码中只能推断的手感、性能或可用性问题要明确标为待运行态核实，不能把固定时长、弹簧参数或主观偏好写成已证实缺陷。

优先级依次是：任务受阻、误操作或数据损失；权限和状态不一致；无障碍与输入路径缺失；明显响应或性能风险；最后才是层级、文案、一致性和工艺。没有可操作问题时明确说明，并列出仍未覆盖的运行态、设备或真实用户证据。

## 准出门槛

- Purpose、主要任务、信息层级和平台模式有明确依据。
- 真实状态、权限、反馈、失败恢复和不可逆后果表达清楚。
- 窗口、文字大小、输入方式和辅助技术变化后仍能完成核心任务。
- 内容优先于容器和效果；材质、动效和情绪细节有语义且不妨碍任务。
- 交互即时、动效连续且可打断，取消或 Reduce Motion 后状态仍正确。
- 报告明确区分已验证、仅静态检查和尚未验证的部分。
